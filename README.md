# Бот дневника питания

Пишешь или говоришь боту в Telegram, что съел. Вечером он уточняет, чего не хватает для подсчёта, и присылает отчёт по КБЖУ, сахару, клетчатке и минералам. Все данные хранятся в Google Таблице «Дневник питания (бот)».

## Как работает

- **На каждую запись бот сразу отвечает** разбором и полной картиной дня: калории, Б/Ж/У, сахар, клетчатка и минералы против нормы. ⏳ — сколько ещё осталось, ✅ — в норме, 🔺 — перебор. Если чего-то не хватает (граммы, место, вкус, масло), он тут же задаёт вопрос с кнопками. Отвечать можно кнопкой, реплаем (текстом или голосом) или просто сообщением. Работают ответы вроде «как вчера»: бот видит историю за последние дни.
- **Уточнение старой записи.** Вчера написал «гранатовый сок», а сегодня прислал фото бутылки с подписью «вчера был он же». Бот поймёт, что это уточнение, а не новый сок: заменит вчерашнюю строку и покажет обновлённый итог того дня. Дважды сок не посчитается.
- **Чеки.** Фото чека — это покупки, а не еда. Бот сохраняет товары на лист «Покупки» и спрашивает, что из этого ты съел. В подписи к фото можно сразу написать: «съел хлеб, 4 куска». Потом «съел творог» бот сопоставит с купленным и возьмёт бренд и вес из чека.
- **Правки.** Отредактируй своё сообщение, и бот пересчитает запись («✏️ Исправил»).
- **Сутки начинаются в 05:00.** Всё, что съел ночью, идёт во вчерашний день. В 05:00 бот один раз присылает итог за прошедший день. Неотвеченные позиции он считает «примерно», но ответить на вопрос можно и позже. Вечером бот сам ничего не пишет.
- **Справочник** пополняется сам. Без вопросов бот берёт блюдо из справочника только при совпадении почти 1 в 1: место, блюдо, вкус и объём.
- **«Че съесть?»** Команда `/eat` или просто текст «че съесть», «что бы съесть сладкое». Бот смотрит, сколько осталось до нормы, сколько сейчас времени и что ты недавно покупал, и предлагает три варианта.
- **Рецепты.** Команда `/recipe` или текст «хочу что-то с яйцами», «рецепт сырников», «что приготовить из курицы». Бот предлагает 3 простых рецепта с учётом твоих вкусов (что ты чаще всего ешь), продуктов дома и остатка КБЖУ. Для каждого — граммовка на порцию, шаги и КБЖУ.
- **Меню на день.** `/plan` или «составь меню на завтра», «рацион на сегодня»: 4–5 приёмов пищи со временем, граммовкой и КБЖУ, в сумме под твою норму. Если меню на сегодня — только на оставшиеся приёмы.
- **Что купить.** `/shop` или «че купить в ВкусВилл»: конкретные товары под остаток КБЖУ.
- **Вопросы своими словами** («чем перекусить», «как добрать белок») бот тоже понимает: это совет, а не запись еды.
- Под советами есть кнопки **«✅ Съел 1/2/3»**: нажал — и вариант записан в дневник. Если готовил с изменениями, ответь на сообщение с рецептом реплаем: «сделал второй, но без тоста и с сыром 30 г». Бот учтёт и рецепт, и изменения.

Нормы, допуск, время и модель меняются прямо в таблице, на листах «Нормы» и «Настройки».

Команды: `/day` (отчёт за сегодня на текущий момент), `/eat` (что съесть), `/recipe` (рецепты), `/plan` (меню на день), `/shop` (что купить), `/status` (что ждёт ответа), `/help`.

## Установка (примерно 30 минут, удобнее с ноутбука)

### 1. Бот в Telegram
1. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot` и придумай имя.
2. Сохрани **токен** вида `123456:ABC...`.

### 2. Ключ Gemini
1. Открой [Google AI Studio](https://aistudio.google.com/apikey). Из России понадобится VPN.
2. Нажми **Create API key** и сохрани ключ.
3. Проверь в AI Studio, что модель из листа «Настройки» (`gemini-3.6-flash`) доступна на бесплатном уровне. Если нет, впиши туда другое точное имя модели.
   На бесплатном уровне Google может использовать запросы для улучшения своих продуктов.

### 3. Доступ бота к таблице (служебный аккаунт Google)
1. Открой [Google Cloud Console](https://console.cloud.google.com/) и создай проект, например `food-bot`.
2. В разделе **APIs & Services → Library** найди **Google Sheets API** и нажми **Enable**.
3. В разделе **IAM & Admin → Service Accounts** нажми **Create service account**, введи любое имя и нажми **Done**.
4. Открой созданный аккаунт, перейди на вкладку **Keys → Add key → Create new key → JSON**. Скачается файл, храни его как пароль.
5. Скопируй email служебного аккаунта (вида `...@...iam.gserviceaccount.com`).
6. Открой таблицу «Дневник питания (бот)», нажми **Настройки доступа**, вставь этот email и выбери **Редактор**.

### 4. Репозиторий на GitHub
1. Создай **приватный** репозиторий, например `food-bot`.
2. Загрузи туда все файлы из архива **вместе с папкой `.github`**. Проще всего перетащить содержимое распакованной папки на страницу репозитория (кнопка *uploading an existing file*). Скрытая папка `.github` тоже должна загрузиться.
3. Открой **Settings → Secrets and variables → Actions → New repository secret** и добавь секреты:

| Имя | Что вставить |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather |
| `GEMINI_API_KEY` | ключ из AI Studio |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | всё содержимое скачанного JSON-файла |
| `SPREADSHEET_ID` | `1BtHZUEC9AOZXmmsbI-m_QYvAkMalooOCf0E-O2e24kc` |

### 5. Первый запуск
1. Напиши своему боту `/start`.
2. На GitHub открой **Actions → food-bot → Run workflow**.
3. Бот пришлёт твой **chat id**. Добавь его секретом `TELEGRAM_CHAT_ID`.
4. Снова напиши `/start` и запусти **Run workflow**. Должна прийти справка.

С этого момента бот работает по расписанию сам.

### 6. Мгновенные ответы (приёмщик)
Без этого шага бот забирает сообщения только при запуске по расписанию в 05:01. С приёмщиком отвечает примерно через минуту после сообщения. Удобнее делать с ноутбука.

**Токен GitHub**, чтобы приёмщик мог запускать бота:
1. GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Name: `food-bot-receiver`, Expiration: максимальный срок. Repository access: **Only select repositories → food-bot**.
3. Permissions → **Actions: Read and write**. Нажми **Generate token** и скопируй токен (начинается с `github_pat_`).

**Скрипт при таблице:**
1. Открой таблицу «Дневник питания (бот)» → **Расширения → Apps Script**.
2. Удали всё, что там есть, и вставь содержимое файла [`apps_script/Code.gs`](apps_script/Code.gs).
3. В строках `TELEGRAM_TOKEN` и `GITHUB_TOKEN` вставь токен бота и токен GitHub (внутри кавычек). Нажми 💾.
4. Сверху выбери функцию **setup** → **Выполнить** → разреши доступ. Google предупредит, что приложение не проверено: «Дополнительные настройки → Перейти на страницу…».
5. Внизу в журнале должно появиться «Готово!». Напиши боту, и ответ придёт примерно через минуту.

**Мгновенная доставка (вебхук), по желанию:** в редакторе нажми **Развернуть → Новое развертывание** → ⚙ **Веб-приложение**. «Выполнять от имени»: меня, «У кого есть доступ»: все. Нажми **Развернуть**, потом снова запусти **setup**. Если вебхук начнёт сбоить, скрипт сам вернётся к опросу раз в минуту.

Пока бот думает, в Telegram показывается «печатает…».

Если что-то пошло не так, запусти функцию **stop**, и бот вернётся к работе по расписанию.

## Полезно знать
- **Опоздания.** GitHub запускает расписание с опозданием, обычно на 5–20 минут.
- **Минуты.** С приёмщиком каждое сообщение — это отдельный запуск примерно на минуту. При 20–30 сообщениях в день выходит 1000–1500 минут в месяц из 2000 бесплатных для приватного репозитория. Сколько уже потрачено, видно в GitHub → Settings → Billing. Если не хватает, можно сделать репозиторий публичным: для публичных минуты не ограничены, а секреты и таблица всё равно остаются закрытыми.
- **Точность.** Минералы — это оценка модели, а не лабораторные данные. Смотри на них как на тенденцию.
- **Если что-то сломалось,** смотри лог на вкладке **Actions**: там видно, на каком шаге ошибка.
- **Поиск в интернете.** Если поиск даёт ошибки или упирается в лимит, бот сам повторит запрос без поиска. Совсем выключить его можно в «Настройках» (`web_search` = `нет`).

## Структура
```
bot/main.py      запуск: забрать сообщения → обработать → сохранить
bot/logic.py     дни, вопросы, напоминания, отчёты
bot/gemini.py    промты и запросы к Gemini
bot/store.py     чтение и запись Google Таблицы
bot/telegram.py  Telegram Bot API
apps_script/     приёмщик: мгновенная передача сообщений из Telegram
tests/           офлайн-тесты логики: python tests/test_logic.py
```
